## Nội dung đã thực hiện (Buổi 1 - Buổi 6)

### Buổi 1 (`buoi1`)
- Cài đặt Flutter SDK, Android Studio, AVD
- Tạo Flutter project `casestudy1_app`
- Chạy thử ứng dụng trên Android Emulator
- Khởi tạo Git và push lên nhánh `main`
- Tạo và checkout nhánh `buoi1`

### Buổi 2 (`buoi2`)
- Checkout nhánh `buoi1` và commit lên thành nhánh `buoi2`.
- Xây dựng UI giống yêu cầu (màn hình chào mừng Welcome).

### Buổi 3 (`buoi3`)
- Checkout nhánh `buoi2` và commit lên thành nhánh `buoi3`.
- Xây dựng UI Thêm giao dịch, Sửa giao dịch, kiểm tra dữ liệu và danh sách giao dịch CRUD trong bộ nhớ.

### Buổi 4 (`buoi4`)
- Checkout nhánh `buoi3` và commit lên thành nhánh `buoi4`.
- Xây dựng màn hình Dashboard (thẻ số dư, tổng thu/chi, danh sách giao dịch và thanh điều hướng dưới).

### Buổi 5 (`buoi5`)
- Checkout nhánh `buoi4` và commit lên thành nhánh `buoi5`.
- Thiết kế và xây dựng database cho ứng dụng bằng SQLite (`sqflite`, `DatabaseHelper`, model `Transaction` hỗ trợ `toMap`/`fromMap`).

### Buổi 6 (`buoi6`)
- Checkout nhánh `buoi5` và commit lên thành nhánh `buoi6`.
- Hoàn thiện các màn hình thêm, sửa và load thông tin giao dịch lên màn hình Dashboard qua `TransactionRepository`.
- Hoàn thiện `casestudy1_app` (màn hình giao dịch, bộ lọc giao dịch, màn hình thống kê, màn hình cá nhân và điều hướng 4 tab).
